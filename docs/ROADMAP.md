# Development Roadmap

> Incremental delivery plan reference for RepoPilot.

Milestone 1 establishes the project scaffold, Milestone 2 delivers the landing experience, and Milestone 3 connects repository intake to the backend.

## Milestone 4 - Lightweight Repository Inspection

Inspect public GitHub repositories through the GitHub REST API without cloning code. The outcome is normalized metadata, language data, root-level structure, and technology signals.

## Later milestones

Later milestones add deeper static analysis, engineering reports, job orchestration when work becomes long-running, and deployment.
